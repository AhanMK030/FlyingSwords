# Flying Swords / 飞剑

A mod for **Pathfinder: Wrath of the Righteous**, featuring hovering flying swords, ten legendary Chinese swords, the Sword Sage class, supporting equipment, and mythic abilities. Includes custom weapon models, combat and sword-riding animations, inventory icons, and Chinese/English localization.

## Download and install

Download the main `FlyingSwords-vX.Y.Z.zip` archive from [Releases](https://github.com/AhanMK030/FlyingSwords/releases/latest), then install it with **Unity Mod Manager**. Requires [TabletopTweaks-Core](https://github.com/Vek17/TabletopTweaks-Core).

All runtime models and animations are included in the main archive. You do not need a separate animation source package.

## UMM updates

Install version **0.10.3 or later** once to add the update address to your installed `Info.json`. UMM can then check `Repository.json` for subsequent releases. Download and install updates while the game is closed.

## Weapons and merchants

Flying swords are exotic, two-handed ranged weapons: **1d10 piercing damage, 30-foot range, 19–20/x2 criticals**, with cold iron and Wisdom-based attack and damage.

| Act | Merchant | Newly available swords |
| --- | --- | --- |
| 1 | Joran Vhane, outside Defender's Heart | Chengying, Yuchang (+1) |
| 2 | Wilcer Garms, crusader camp | Zhanlu, Chixiao (+2) |
| 3 | Wilcer Garms, Drezen | Tai'a, Seven-Star Longyuan (+3) |
| 4 | Bartender, Bad Luck Tavern, Alushinyrra | Chunjun, Ganjiang and Moye (+4) |
| 5 | Wilcer Garms, Drezen | Chengying the Formless, Xuanyuan (+5) |

Unpurchased equipment carries forward to later acts. Supporting equipment is available from Act 1. The Lord of Nothing tavern equipment merchant also offers the swords through its stock progression.
