# 飞剑 0.10.9

0.10.9：剑化分光与炁化万剑使用飞剑攻击的剑指姿态；敌人头顶的飞剑放大1.5倍。全部飞剑重新制作细亮芯、纹理剑气及柔光三层尾迹，并附带匹配游戏渲染的专用材质。详见 TrailDesign.md。

0.10.9 gives both AoE sword techniques the ordinary sword-finger pose and enlarges their falling blades by 1.5×. All eleven sword models now use layered, textured trails with a bundled native-compatible shader. See TrailDesign.md.

0.10.8：清除飞剑继承的弓箭挥击、命中及投射物声音。普通飞剑每次实际攻击只播放一次自定义音效，按角色独立交替，不依赖模型或动画能否创建；日志记录每次播放事件及Wwise播放ID。剑遁改为流光先到达，等待实际瞬移完成，再显现人物并落地；修复原版淡入流程提前显示人物的问题。

0.10.8 removes inherited bow animation, impact and projectile audio. Ordinary flying-sword attacks post exactly one alternating custom cue per actual attack, independently of visual creation; the log records the event and Wwise playing ID. Sword Escape now waits for the travelling sword to arrive and native teleport to complete before the body emerges and lands. Native fades cannot reveal the body early.

0.10.7：剑域按当前飞剑攻击范围威胁敌人，每轮借机次数额外增加感知调整值，保留原有远程攻击规则。剑仙3级新增剑遁：1剑元、迅捷动作、瞬移30尺，本轮飞剑攻击＋2，附带0.30秒人剑合一流光动画与独立图标。神识先攻改为半剑仙等级＋感知调整值，察觉保持半等级。旧剑仙读档自动补齐剑遁。

0.10.7 updates Sword Domain to threaten the equipped sword’s attack range and adds Wisdom to AoO capacity while retaining ranged attack rules. At level 3, Sword Escape spends 1 essence as a swift action to teleport 30 feet and gain +2 flying-sword attacks for the current round, with a dedicated 0.30-second light animation and icon. Spiritual Awareness adds Wisdom to initiative alongside half class level; Perception retains half class level. Existing Sword Sages receive Sword Escape on loading.

0.10.6移除神话能力“神话剑技”的选择入口，新增普通专长“额外剑技”：前置剑仙1级，额外选择一项当前分支的剑技，沿用原有等级、前置与不可重复限制。沿用剑技图标并提供中英文文本。旧存档已获得的神话剑技及其已选剑技保留兼容数据；可通过重训释放旧神话能力选择。

0.10.6 retires Mythic Sword Techniques from available mythic abilities and adds the ordinary feat Extra Sword Technique, requiring sword sage level 1. It grants one extra technique from your current path with the normal level, prerequisite and no-duplicate rules. Existing saves keep previously granted techniques; retraining can release the retired mythic ability choice.

0.10.5加入三段玩家提供的音效，由Wwise 2019.2.15转换。剑化分光、炁化万剑每次有效出招播放一次拔剑声；飞剑实际飞出攻击时，按每个角色的攻击顺序交替播放剑击高频声与剑气声。待机、御剑移动和群攻派生攻击不会重复触发普通攻击音效。声音使用游戏原有Weapons通道及空间衰减，随原版音效音量设置调整。

0.10.5 adds three player-supplied sounds converted using Wwise 2019.2.15. Sword Splitting into Light and Qi Becomes Myriad Blades play one draw cue per successful activation. Ordinary flying-sword launches alternate the two attack sounds independently for each character. Uses the game's Weapons audio bus and positional attenuation. No additional audio package is required.

0.10.4修复倒地／起身及中断御剑移动后悬浮飞剑可能保持隐藏的问题：定期核对实际御剑状态并恢复悬浮模型、渲染器和动画更新；倒地时退出自定义姿势，恢复后重新接入。动画层暂时接入失败会延迟重试。

同时修复乔兰等商人的总商品表绕过章节限制的问题：识别总表附加的章节武器表，打开商店时清理提前出现的高阶飞剑，兼容旧存档。第一章只出售承影、鱼肠两柄＋1飞剑；配套装备继续从第一章出售，玩家卖回的物品保留。

0.10.3配置GitHub公开发布与UMM更新地址。首次安装此版后，UMM可通过公开更新清单检查后续版本。所有模型和动画包含在主安装包中。

0.10.2调整御剑飞行：剑仙1–5级速度＋10尺，6–10级＋20尺，11级起＋30尺，旧存档自动重新计算。重锋御剑额外将半倍感知调整值加入飞剑武器伤害，向下取整，不要求开启猛力攻击，并保留原有猛力攻击效果。同步更新中英文说明。

0.1.7固定站定御剑时的上半身：捕获角色自身的脊柱、肩部、颈部和头部姿态，阻止原版攻击动画继续扭动或移动这些部位。下半身沿用0.1.6的自身比例站姿，只有双臂与手指播放御剑动作，角色整体转向仍由游戏控制。移动、施法、受击、倒地、闪避、交互及关闭姿态时恢复原版动作。固定数据取自当前动画流，不使用参考角色的骨骼角度；安装后必须完全退出并重启游戏。

0.1.6修复0.1.5站姿引起的下半身畸变及整个人背向目标的问题。动作层不再覆盖参考角色的骨盆、脊柱和锁骨角度，保留游戏原生身体朝向；手臂与剑指按角色的实际OrientationDirection伸向前方。双腿按当前角色的髋宽、腿长及原生扭转姿态调整，脚距随自身比例变化，避免固定6厘米间距造成鞋腿相交。保留所有腿部和形体调整骨骼的局部间距；站姿只锁定动画流中捕获的自身骨盆姿态，并有限调整高度保持直腿。移动、施法、受击等仍恢复原版动作。伸臂节奏与手指屈收保留Blender制作的曲线。真实角色、裙甲和披风的视觉效果仍需重启游戏后实测。

0.1.5优化御剑攻击动作：战斗站定时双腿伸直、双脚并拢，下半身固定，不再沿用原版抛掷攻击的迈步与骨盆晃动。右手从胸前持诀向前伸臂，食指、中指保持并拢伸直、指向角色前方；左手保持腰背后。0.60秒引剑动作包含0.18秒伸臂、0.18秒前指及0.24秒收回。开始攻击时伸臂，飞剑发射时进入前指段，连续攻击重新衔接动作。移动时立即恢复原版腿部与骨盆动作；施法、受击、倒地、闪避和交互等保留原版动作。站姿只控制人形局部骨骼，不移动角色实体，不改攻击次数、命中、伤害或射程。

0.1.4新增飞剑固有特性“御剑”：使用感知调整值取代敏捷调整值计算攻击，武器伤害加入一次感知调整值，即使感知低于敏捷也使用感知。感知伤害倍率为×1，不因双手占用自动变为×1.5；负感知调整值按原版属性规则计入。该特性通过武器自身的原版附魔事件生效，出现在物品特性说明中，价格附魔等值为0，保留寒铁与其他附魔。旧存档中的飞剑在载入或装备时补齐特性，重复检查不会叠加；不需要重新领取。

0.1.3新增御剑结印姿态：右手在胸前持剑指，食指与中指并拢伸直，无名指、小指收拢，拇指内扣；左手置于腰背后。Blender制作起诀、持诀、引剑三段动作，战斗持诀时轻微呼吸起伏，发射飞剑时小幅引动右腕后归位。动作通过原版动画图的局部动画任务作用于23个上身与手部骨骼，保留原版腿部移动、动画事件与攻击结算。施法、倒地、受击、闪避、交互及特殊攻击时交还原版动作；卸下飞剑、关闭姿态、角色视图更换时移除本模组的动画层。只接入具有对应骨骼的人形；变形或非人形骨骼不会套用该姿态。在Mod页面可切换“启用御剑结印姿态”。详见开发源工程中的SwordSeal_Design.md。

0.1.2新增原版附魔场景特效：每柄悬浮飞剑建立与原版长剑相同用途的剑面、剑尖、中心及攻击尾迹挂点；读取当前武器生效的附魔和原版外观覆盖，使用其原有特效资源。附魔随剑身出击与回收，重复资源只显示一次，失效、移除或卸下时清理。保留原版附魔禁止生成特效的设置；没有原版特效的附魔不会强加光效。特效密度与粒子尺寸参考原版长剑，附魔显示不改动攻击与伤害结算。武器图标替换为透明背景、斜向构图的绘制版银色叶纹飞剑，匹配原版装备图标风格。

通过 Unity Mod Manager 安装压缩包，或将包内 FlyingSwords 文件夹复制到游戏 Mods 目录。完全退出游戏后重启。在 Unity Mod Manager 的“飞剑”页面点击“领取一柄测试飞剑”，武器会加入队伍共享背包。需要先载入存档；按钮不会自动授予熟练。基础寒铁飞剑保留测试领取入口；十把名剑在指定商人处售卖，并可在Mod页面选择后领取用于测试。

武器专攻、精通重击等使用武器类别的参数选择中提供“飞剑”。精通重击保留原版武器熟练与基础攻击加值+8要求，使飞剑重击范围从19–20扩大至17–20；已提前缓存的参数列表也会补齐该选项。独立类别采用固定编号918001；不将弓或其他既有武器改名为飞剑。不熟练减值、远程专长、双手占用与原版攻击结算继续适用。

装备飞剑后，剑身在人物肩侧／身后浅扇形悬浮，手上和背部不生成武器模型。剑数按原版完整攻击列表中使用飞剑的攻击数计算，包含加速等额外攻击，不把其他肢体攻击计入。普通单次攻击只发射一柄；多重攻击依次轮换。出击剑从其悬浮位置发射，跟随实际游戏投射物的位置，在其命中／结束后播放回收动画；模型动画不再触发伤害。白色尾迹仅在出击和回收时发射，宽度约1.5厘米，逐渐变细、淡出。移动时随行，传送时清空尾迹并归位，卸下武器、死亡、视图更换时清理旧显示对象。
